### 📜 منصة التوثيق واعتتماد الشهادات الرقمية لتجمع حفر الباطن الصحي 
منصة متكاملة لإصدار وتحقق الشهادات الرقمية باستخدام تقنيات حديثة لضمان الأمان والسرعة.

* 🔗 **رابط المعاينة الحية:** [اضغط هنا لمعاينة التطبيق الحي](https://certificate-hafar.vercel.app)

#### 🛠️ التقنيات المستخدمة:
* **Frontend:** React / Vite / Tailwind CSS
* **Backend & Auth:** Firebase (Firestore & Authentication)
* **Deployment & CI/CD:** Vercel & GitHub Actions
